邮件外发自助工具 · Mail Sender Studio

填写你自己的邮箱、授权码、收件人与模板 → 生成可运行的发送脚本 → 在本机一键发送（支持追踪像素）。本页不会上传、不会保存你填写的任何数据。

1 SMTP 配置（你自己的邮箱）

2 收件人

批量外发时在此粘贴全部收件人。单封测试可直接用第 5 节的「测试收件邮箱」。

3 邮件模板（你自己的文案）

正文示例（HTML）：<p>Hi {handle},</p><p>Welcome to our campaign!</p><p><a href="https://你的产品链接">Check it out</a></p>

4 追踪像素（可选）

常见接入：填你的像素服务地址，如 https://your-tracking-service.com/pixel?id={key}；每封邮件的 key 唯一且自动生成，方便后台对账。

5 生成脚本

⚠️ 生成的脚本内包含你填写的授权码，属于机密文件，请勿把脚本转发给他人或上传到公开位置。
运行方法：Mac / Linux 终端执行 python3 send.py；Windows 执行 python send.py。需要本机安装 Python 3（若没有，先到 python.org 安装）。

FAQ

问题说明
网站会保存我的信息吗？不会。本页是纯前端页面，所有内容只在你浏览器里用于生成脚本，不上传、不存储。
为什么是生成脚本而不是网页直接发？网页（GitHub Pages 静态托管）无法直接连接 SMTP 发信；生成的 Python 脚本在本机运行即可完成发送，稳定且支持大批量。
发件邮箱用哪种？任意支持 SMTP 的邮箱：飞书邮箱（smtp.feishu.cn:465）、Gmail（需应用专用密码）、QQ/163（需开启 SMTP 并获取授权码）等。
追踪像素怎么生效？收件人打开邮件时，邮件内的图片会请求你的像素 URL；脚本为每封邮件生成唯一 key，你在后台按 key 统计打开即可。
